# Parempi hoiva vähentämällä hukkaa

Liberaalipuolueen sote-politiikkasuositus: sote-menojen hillintä palveluja heikentämättä, analyysi hallituksen sote-linjasta 2023–2027 sekä alue-erittely ja sanasto.

Sivusto: https://juntunen-ai.github.io/liberaali-sote/

- `docs/` – julkaistava staattinen sivusto (GitHub Pages: branch `main`, kansio `/docs`)
- `src/` – lähdesisältö (Claude Docs -viennit HTML-muodossa)
- `build.py`, `style.css`, `tip.js` – sivuston generointi: `python3 build.py`

Laskelmat perustuvat [Budjettihaukan](https://github.com/juntunen-ai/budjettihaukka) aineistoon. Luvut ovat arvioita; lähteet on lueteltu kunkin sivun lopussa.
